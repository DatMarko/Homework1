# Project goals

This Pokémon Team Builder is my learning project. I'm using it to build the
skills listed in Cohere's Forward Deployed Engineer, Agentic Platform posting,
and I plan to apply in 6 to 12 months. I'm at an early level: comfortable with
Python basics, Git, and organizing code, and just starting web and API work.

The app needs to grow through these stages, in order:
1. Web version: backend, database, frontend, automatic tests, logging, deployed online
2. Rules assistant: RAG over move, ability, and tournament rules text, using a vector database
3. Team coach: an agent that plans and executes multi-step tasks, built with both
   ReAct and Plan-and-Execute, once by hand and once with an orchestration framework
4. Scorecard: an evaluation framework measuring the agent's accuracy, safety, and latency
5. Real users: features built from a written spec based on player feedback
6. Audit log: a traceable record of every step the agent takes

# How I want you to work with me

- The goal is for me to learn, not for the app to get finished fast.
- Before writing code, explain the concept in plain language and what we're about to do.
- Give me a hint and let me try first. Review what I write and tell me what to fix and why.
- Write code yourself only when I ask, or for boilerplate with nothing to learn in it.
- Hold me to professional standards: tests, clear names, small commits, logging.
- When I use a term wrong or skip a step a professional wouldn't, say so.
